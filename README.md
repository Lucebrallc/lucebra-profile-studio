## ✨ Features

- **⚡ Split-Screen Real-Time Preview:** Watch your profile render instantly as you type with genuine GitHub Flavored Markdown (GFM).
- **🛠️ 150+ Tech Stack Badges:** Fast searchable grid with 7 categories (Languages, Frontend, Backend, Cloud & DevOps, Databases, AI/ML, Tools) and multiple badge styles (`for-the-badge`, `flat-square`, `plastic`).
- **🎓 Verified Certifications & Accreditations:** Embed authenticated skill credentials linked directly to the [Lucebra Global Credential Registry](https://www.lucebra.com/verify).
- **📊 Dynamic GitHub Stats & Metrics:** One-click integration of commit streak stats, top languages cards, and GitHub trophies with custom themes (Tokyo Night, Dracula, Radical, Cobalt).
- **✍️ Animated Typing SVG Banner:** Add an eye-catching typing animation to your hero header without writing code.
- **📥 One-Click Export:** Instantly copy formatted Markdown to your clipboard or download as a ready-to-commit `README.md`.
- **🌙 Dark & Light Themes:** Crisp, executive design system with glassmorphism and smooth responsive UI.

## 🚀 Quick Start (Running Locally)

This project has **zero build dependencies** and runs directly in any modern browser.

### Option 1: Serve Locally
```bash
# Clone the repository
git clone https://github.com/Lucebrallc/lucebra-profile-studio.git

# Navigate to directory
cd lucebra-profile-studio

# Start any static local server (e.g. npx serve or python)
npx serve .
# or
python3 -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: 1-Click GitHub Pages Deployment
1. Fork or push this repository to your GitHub account under `https://github.com/Lucebrallc/lucebra-profile-studio`.
2. In your repository settings, go to **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions** (the included `.github/workflows/deploy.yml` will deploy it automatically).
4. Your studio will be live at `https://lucebrallc.github.io/lucebra-profile-studio/`!

## 🛠️ How It Works

1. **Fill in your details:** Enter your name, title, bio highlights, and GitHub username.
2. **Select your tech stack:** Click the technology chips you use daily.
3. **Add verified credentials:** Select the accredited certifications you have completed on Lucebra.
4. **Copy & Commit:** Click **"Copy Markdown"**, navigate to `github.com/<your-username>/<your-username>`, edit your `README.md`, paste, and commit!
